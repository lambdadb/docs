## Changelog

{/* Follow the roadmap and changelog editorial rules in the repository root AGENTS.md. */}

### October 2026

- The [MCP server](/guides/get-started/use-with-mcp#step-2-choose-the-published-package) now limits its stdio receive buffer to 10 MiB and closes the connection on overflow; split large tool inputs into smaller calls.
- Added opt-in experimental [Bayesian hybrid search](/guides/search/hybrid#bayesian-hybrid-query) with explicit candidate budgets and optional reranking through the API, SDKs, CLI, and MCP server.
- Simplified [native embedding configuration](/guides/collections/native-embeddings#collection-schema) to accept an `embedding` block without the legacy flag, with SDK, CLI, MCP, and [Migration CLI mapping support](/guides/migrations/overview#generate-embeddings-from-migrated-text).
- Added query-level [native reranking](/guides/search/native-reranking) with default or custom relevance criteria and final/search score metadata, available through the API, SDKs, CLI, and MCP server.
- Expanded support to all 49 [fixed text analyzer presets](/guides/collections/choose-text-analyzers), including [Elasticsearch analyzer and index-default mapping](/guides/migrations/elasticsearch/migrate-from-elasticsearch#text-analyzer-presets) in the Migration CLI; source credentials now need read access to both mappings and settings.

### September 2026

- Updated [Python SDK runtime requirements](/reference/sdk/introduction#supported-sdk-versions) to Python 3.10–3.13; Python 3.9 users must upgrade Python before updating the SDK.
- Expanded [text analyzer support](/guides/collections/choose-text-analyzers) with Chinese word segmentation, CJK bigrams, and additional language-specific analyzers for multilingual full-text search, supported by the SDKs, CLI, and MCP server; analyzer names must be unique within each field.
- Added [collection descriptions and metadata tags](/guides/collections/manage-collections#configure-a-collection) to help organize collections.
- Added [data versioning](/guides/data-versioning/branches-tags-aliases) with writable branches, immutable tags, mutable aliases, and configurable snapshot retention.
- Released the [LambdaDB CLI](/guides/get-started/use-with-cli) to create collections, import JSONL, and query documents. Available through npm and Homebrew.
- Published the stable [MCP server](/guides/get-started/use-with-mcp) on npm for connecting AI assistants to LambdaDB.

### May 2026

- Added [native embeddings](/guides/collections/native-embeddings) to generate vectors from source text and search with text queries.
- Released the [Migration CLI](/guides/migrations/overview) to migrate existing search data into LambdaDB.

### April 2026

- Added the initial [Free plan](/guides/costs/understanding-costs).

### March 2026

- Launched [LambdaDB Cloud](https://app.lambdadb.ai/auth/signup) public preview across all global AWS regions.
- Released the [Python, TypeScript, and Go SDKs](/reference/sdk/introduction), plus [langchain-lambdadb](https://pypi.org/project/langchain-lambdadb/) and [langchain-lambdadb-js](https://www.npmjs.com/package/@functional-systems/langchain-lambdadb).
