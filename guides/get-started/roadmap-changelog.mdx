Last updated: November 27, 2026

## Up Next

- Query and indexing performance, always
- Explicit partition management: add and delete collection partitions beyond hash-based partitioning
- Continuous sync from PostgreSQL and MongoDB to keep LambdaDB collections up to date as source data changes
- Extended aggregation support beyond keyword facets, including additional bucket and metric aggregations
- Expanded full-text search capabilities, including highlighting and synonym support
- Geo-point indexing and search, including geographic filtering and distance-based sorting

## Changelog

{/* Follow the roadmap and changelog editorial rules in the repository root AGENTS.md. */}

### November 2026

- The Python and TypeScript [Qdrant adapters](/guides/migrations/qdrant/qdrant-sdk-compatibility#filter-support) now preserve boolean grouping in search, scroll, and delete and reject unsupported predicates such as `MatchExcept` before sending a request.
- Added [branch rollback](/guides/data-versioning/branches-tags-aliases#roll-back-a-branch-to-a-tag) to restore a branch's data and index schema from a tag, including a tag that is still waiting for its first snapshot; clients that read the rollback response must accept a `null` `headSnapshot`. Supported by the API, the [SDKs, CLI, and MCP server](/reference/sdk/introduction#supported-sdk-versions).
- Document listing can [sort by up to four fields and include a branch's pending writes](/guides/documents/list-data#sort-and-read-pending-writes), and listing a tag now includes the pending writes it captured. Supported by the API, the [SDKs, CLI, and MCP server](/reference/sdk/introduction#supported-sdk-versions).
- The REST API can [tag pending writes before the first snapshot](/guides/data-versioning/branches-tags-aliases#create-and-list-tags), so clients that read tag responses must accept `null` snapshot IDs, snapshot commit times, and data update times. The [SDKs, CLI, and MCP server](/reference/sdk/introduction#supported-sdk-versions) accept them.
- Added [branch index schemas](/guides/data-versioning/branches-tags-aliases#branch-index-schemas): each branch owns its index schema and can add fields without changing `main`, and a single branch, tag, or alias can be read with its schema. Supported by the API, the [SDKs, CLI, and MCP server](/reference/sdk/introduction#supported-sdk-versions).
- Allowed [creating a branch from a tag](/guides/data-versioning/branches-tags-aliases#create-a-branch-from-a-tag) in the API, SDKs, CLI, and MCP server.
- Branch, tag, and alias lists are now [paginated](/guides/data-versioning/branches-tags-aliases#page-through-ref-lists) and return 10 entries by default; clients that list more refs must follow `nextPageToken`. The SDKs follow it for a complete list and can also read one page at a time; the CLI and MCP server return one page per call.
- Added optional [index field descriptions](/guides/collections/index-types#field-descriptions) to document what each field holds; they can be added, changed, or cleared on existing fields without reindexing. Supported by the [SDKs, CLI, and MCP server](/reference/sdk/introduction#supported-sdk-versions).
- Allowed [consistent reads](/guides/data-versioning/branches-tags-aliases#consistent-reads) through an alias that currently targets a branch, in the API, SDKs, CLI, and MCP server.

### October 2026

- Added [CLI account and project management](/guides/get-started/use-with-cli#manage-your-account-and-projects), usage reports, and [guided coding-agent setup](/guides/get-started/use-with-cli#connect-coding-agents).
- Added [native reranking](/guides/search/native-reranking) and Cohere support for both reranking and [text and image embeddings](/guides/collections/native-embeddings).
- Raised search, fetch, and list [limits](/guides/search/limits) to 1,000.
- Added [Bayesian hybrid search](/guides/search/hybrid#bayesian-hybrid-query) to combine keyword and vector results with automatic score calibration.
- Expanded support to 49 [text analyzer presets](/guides/collections/choose-text-analyzers), including analyzer mappings for Elasticsearch migrations.

### September 2026

- Updated [Python SDK runtime requirements](/reference/sdk/introduction#supported-sdk-versions) to Python 3.10–3.13; Python 3.9 users must upgrade Python before updating the SDK.
- Expanded [text analyzer support](/guides/collections/choose-text-analyzers) with Chinese word segmentation, CJK bigrams, and additional language-specific analyzers for multilingual full-text search, supported by the SDKs, CLI, and MCP server; analyzer names must be unique within each field.
- Added [collection descriptions and metadata tags](/guides/collections/manage-collections#configure-a-collection) to help organize collections.
- Added [data versioning](/guides/data-versioning/branches-tags-aliases) with writable branches, immutable tags, mutable aliases, and configurable snapshot retention.
- Released the [LambdaDB CLI](/guides/get-started/use-with-cli) to create collections, import JSONL, and query documents. Available through npm and Homebrew.
- Published the stable [MCP server](/guides/get-started/use-with-mcp) on npm for connecting AI assistants to LambdaDB.

### May 2026

- Added [native embeddings](/guides/collections/native-embeddings) to generate vectors from source text and search with text queries.
- Released the [Migration CLI](/guides/migrations/overview) to migrate existing search data into LambdaDB.

### April 2026

- Added the initial [Free plan](/guides/costs/understanding-costs).

### March 2026

- Launched [LambdaDB Cloud](https://app.lambdadb.ai/auth/signup) public preview across all global AWS regions.
- Released the [Python, TypeScript, and Go SDKs](/reference/sdk/introduction), plus [langchain-lambdadb](https://pypi.org/project/langchain-lambdadb/) and [langchain-lambdadb-js](https://www.npmjs.com/package/@functional-systems/langchain-lambdadb).
