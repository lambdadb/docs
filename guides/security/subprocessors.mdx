Last updated: October 9, 2026

LambdaDB (Functional Systems Inc.) uses the following subprocessors to process customer data (customer content and account, usage, and billing data):

| Subprocessor | Purpose | Location |
| --- | --- | --- |
| Amazon Web Services (AWS) | Cloud infrastructure — compute, storage, and networking for the LambdaDB service | Customer content: the AWS region selected for the project. Account, authentication, usage, and billing data: us-east-1 (N. Virginia). |
| Stripe | Payment processing | United States |
| Vercel | Website and dashboard hosting | United States |

Account, authentication, usage, and billing data are processed on AWS infrastructure in the us-east-1 (N. Virginia) region.

## Changes to subprocessors

We will update this page before adding or replacing any subprocessor that processes customer data. Questions or objections may be directed to [contact@lambdadb.ai](mailto:contact@lambdadb.ai).
