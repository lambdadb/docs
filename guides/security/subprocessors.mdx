Last updated: November 27, 2026

LambdaDB (Functional Systems Corp.) uses the following subprocessors to process customer data (customer content and account, usage, and billing data):

| Subprocessor | Purpose | Location |
| --- | --- | --- |
| Amazon Web Services (AWS) | Cloud infrastructure — compute, storage, and networking for the LambdaDB service | Customer content: the AWS region selected for the project. Account, authentication, usage, and billing data: us-east-1 (N. Virginia). |
| Stripe | Payment processing | United States |
| Vercel | Website and dashboard hosting | United States |
| OpenAI OpCo, LLC | [Native embeddings](/guides/collections/native-embeddings) when selected. Processes document or query text to generate vectors. | Contact LambdaDB for processing locations. |
| Cohere Inc. | [Native embeddings](/guides/collections/native-embeddings) for text and images, or [native reranking](/guides/search/native-reranking) for query text and selected candidate fields, when selected. | Contact LambdaDB for processing locations. |
| TypeSafe AI, Inc. | [Native reranking](/guides/search/native-reranking) when selected. Processes query text, selected candidate fields, and relevance criteria to score results. | Contact LambdaDB for processing locations. |

Account, authentication, usage, and billing data are processed on AWS infrastructure in the us-east-1 (N. Virginia) region.

## Changes to subprocessors

We will update this page before adding or replacing any subprocessor that processes customer data. Questions or objections may be directed to [contact@lambdadb.ai](mailto:contact@lambdadb.ai).
