Last updated: November 27, 2026

LambdaDB (Functional Systems Corp.) uses the following providers to process customer content and account, usage, or billing data. An inference provider receives data only when you use [native embeddings](/guides/collections/native-embeddings) or [native reranking](/guides/search/native-reranking) with that provider.

| Subprocessor | Purpose | Data processed | Processing location |
| --- | --- | --- | --- |
| Amazon Web Services (AWS) | Compute, storage, and networking | Customer content | AWS region selected for the project |
| Amazon Web Services (AWS) | Account and service administration | Account, authentication, usage, and billing data | US East (N. Virginia), `us-east-1` |
| Stripe | Payment processing | Billing and payment information | United States |
| Vercel | Website and dashboard hosting | Website and dashboard requests | United States |
| OpenAI OpCo, LLC | Text embeddings | Document or query text submitted for embedding | Contact LambdaDB for the applicable processing location. |
| Cohere Inc. | Embeddings and reranking | Text or image inputs for embedding. Query text and selected candidate fields for reranking. | [United States (Cohere-hosted API)](https://trustcenter.cohere.com/?format=html) |
| TypeSafe AI, Inc. | Reranking | Query text, selected candidate fields, and relevance criteria | [United States](https://help.typesafe.ai/articles/5974925716) |

## Changes to subprocessors

We will update this page before adding or replacing any subprocessor that processes customer data. Questions or objections may be directed to [contact@lambdadb.ai](mailto:contact@lambdadb.ai).
