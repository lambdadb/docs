## Large results

When a response reaches the inline payload threshold, LambdaDB stores the returned documents separately and responds with HTTP `200`, `isDocsInline: false`, an empty `docs` array, and a presigned `docsUrl`. The [inline threshold](/guides/get-started/limits#search-and-reads) is not a total-result cap. Other query limits still apply.

For direct REST requests, check `isDocsInline` before reading `docs`. When it is `false`, send a `GET` request to the complete `docsUrl` without changing its query parameters or forwarding your LambdaDB API key. The downloaded JSON is an array of result items, not an object containing a `docs` field. An empty inline `docs` array in this case does not mean there are no results.

Fetch and list responses use the same download mechanism. The high-level collection methods in the recommended [Python, TypeScript, and Go SDK releases](/reference/sdk/introduction#supported-sdk-versions) download these results automatically.

<Tip>

  To reduce result size and download overhead, choose a lower `size` value,
  or `includeVectors=false` (Python: `include_vectors=False`) to exclude vector values from the result.

</Tip>
