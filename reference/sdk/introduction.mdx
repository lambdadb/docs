## Supported SDK versions

The examples use these stable releases, which include data versioning and all 16 [text analyzers](/guides/collections/choose-text-analyzers):

| SDK | Recommended release | SDK guide |
| :-- | :------------------ | :-------- |
| Python | [0.10.0](https://pypi.org/project/lambdadb/0.10.0/) | [Python data versioning](https://github.com/lambdadb/lambdadb-python-client/blob/v0.10.0/docs/sdks/versioning/README.md) |
| JavaScript/TypeScript | [0.6.0](https://www.npmjs.com/package/@functional-systems/lambdadb/v/0.6.0) | [TypeScript data versioning](https://github.com/lambdadb/lambdadb-typescript-client/blob/v0.6.0/docs/data-versioning.md) |
| Go | [0.5.0](https://github.com/lambdadb/go-lambdadb/releases/tag/v0.5.0) | [Go data versioning](https://github.com/lambdadb/go-lambdadb/blob/v0.5.0/docs/sdks/versioning/README.md) |

Python SDK 0.10.0 requires Python **3.10–3.13**. If you use Python 3.9, stay on `lambdadb==0.9.0` until upgrading Python; that release does not include the additional analyzer names. Go SDK 0.5.0 requires Go **1.22 or later**. Server support is also required for the features you use.

## Data versioning support

The minimum stable versions for collection, branch, tag, and alias APIs remain Python **0.9.0**, JavaScript/TypeScript **0.5.1**, and Go **0.4.0**. Use the recommended releases above when you also need the expanded analyzer set.

Start with the [SDK examples](/guides/data-versioning/branches-tags-aliases#use-the-sdks) to create a branch, write to it, and read from a selected ref. The language-specific guides cover tags, aliases, pagination, and bulk uploads. Python also provides async methods; JavaScript/TypeScript uses promises and async iterators, while Go uses `context.Context`.

For analyzer support through the SDKs, CLI, and MCP server, see [analyzer SDK compatibility](/guides/collections/choose-text-analyzers#sdk-compatibility).

REST timestamps use Unix epoch milliseconds. Python exposes numeric timestamps with datetime helpers such as `created_at_dt`; the TypeScript collection-scoped client returns `Date` values; Go provides time getters. Branch parent and snapshot fields can be null, so check them before accessing their fields.
